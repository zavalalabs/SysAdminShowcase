This macOS folder under my repository is my way of trying to help lower the barrior of entry 
for new systemsa administrators in teh macOS space. Due to the differences in macOS over the years
we have seen the migration form a more UNIX like operating system to something that is more unique
and specific to apple. While the os still maintains many unix like toolings in teh background. 
the delivery of macos operating system updates and core components that are mainly unique to apple under
the hood. have made the system one of the more challenging operating systems to manage from a systems
administration perspective.

Some tooling that many have used in the past keeps chanigng and older tools keep getting depricated. 
This is seen in the more recent moves from MDM CConfiguration profiles to now apple DDM (Delaritive device mangment) or delcorations
that change how the system is managed from a MDM solution like JAMF pro. Even with the latest OS versions we have seen
moving away from extentions previously leveraged to more modern configurations and detection methodologies.
